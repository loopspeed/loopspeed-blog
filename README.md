# Loopspeed Blog

The **Loopspeed Blog** is a modern blog platform built with **Next 15** and authored entirely in **MDX**. It leverages Next.js's App Router (`app/` directory structure) for efficient, file-based routing and uses **TypeScript** throughout the codebase for robust type safety. Blog posts are stored in the `resources/posts/` directory and written in MDX format, allowing rich content with embedded React components.

---

## Features

- **Next.js 15 & App Router:** Built on the latest Next.js framework, using the App Router for modular, performant routing and server-side rendering.
- **MDX Content with Custom Components:** All posts are written in MDX, enabling JSX in Markdown. Custom MDX components handle enhanced rendering for elements like headings, code blocks, blockquotes, callout asides, and video embeds, providing a tailored reading experience.
- **GitHub-Style Markdown:** Supports GitHub-flavoured Markdown via `remark-gfm`, so you can use tables, task lists, strikethroughs, and other GFM features in posts.
- **Beautiful Code Highlighting:** Syntax highlighting is powered by `rehype-pretty-code` using the GitHub Dark Dimmed theme. Code blocks are automatically formatted with VS Code-quality highlighting for clarity and readability.
- **Tailwind CSS Styling:** Styled with Tailwind CSS for a modern, responsive design. Utility-first classes and Tailwind’s typography plugin ensure consistent, clean styling across the blog.
- **TypeScript & Modern Tools:** The project is developed in TypeScript and uses modern libraries (React Three Fiber, GSAP, etc.) where appropriate, ensuring maintainable and up-to-date code practices.

## Article Types

The blog features a range of article types and topics, including:

- **Tutorial:** Step-by-step guides and tutorials.
- **React:** Articles on React.js and related libraries.
- **Three.js:** 3D graphics and creative coding with Three.js.
- **Particles:** Generative art and particle animations.
- **HTML Canvas:** Canvas API techniques and projects.
- **Next.js:** Tips and projects using Next.js.
- **GSAP:** Animations with the GreenSock Animation Platform.
- **Tailwind:** Styling and UI design using Tailwind CSS.
- **TypeScript:** Strongly-typed JavaScript and coding patterns.
- **Vertex Shader:** GPU vertex programming for custom graphics effects.
- **Fragment Shader:** Pixel-level shader programming for advanced visual effects.
- **WebGL:** Browser-based 3D graphics using the WebGL API.
- **WebGPU:** Next-generation web graphics with the WebGPU API.
